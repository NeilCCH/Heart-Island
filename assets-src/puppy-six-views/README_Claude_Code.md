# 小狗六視角透明 PNG

先閱讀此文件、manifest.json，並實際開啟 images/ 六張圖再接線。檔名依序為正面、左前45度、左側面（鼻朝左）、右側面（鼻朝右）、背面、俯視高角度。俯視並非嚴格正上方投影。

六張已分開、移除下方標籤，以 AI 工具去背為 RGBA PNG。角色是奶油金色幼犬、深棕眼、垂耳、粉藍項圈、金色愛心吊飾。背面吊飾不可見屬正常遮擋。AI 去背可能微調毛髮與細節，不是逐像素保留的原圖。

可依現有專案結構放至 public/assets/puppy/，使用 object-fit: contain 並依 manifest.json 設定實際寬高。保留透明背景、完整耳朵、尾巴與腳掌，不拉伸。不覆蓋原小貓素材。

這些是靜態2D角色素材與建模參考，不是可旋轉3D模型、GLB或已完成動畫。不同角度未作嚴格3D一致性驗證或逐幀配準，不可當動畫sprite。本包未修改程式、未完成網站整合或部署，接入須遵守專案責任邊界與授權。

已目視核對六張視角與無標籤；六張均通過RGBA、全透明及半透明像素檢查。毛髮邊緣仍需在實際網頁底色驗收，未測所有裝置。尺寸詳見manifest.json。

完整性校驗：在解壓目錄執行 `shasum -a 256 -c SHA256SUMS.txt`。校驗包含六張圖片與本說明、manifest，共8個檔案。
