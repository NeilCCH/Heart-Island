# 心靈小島｜小貓能量站 PRD v1.2（引導式自動計數 MVP）

- 日期：2026-10-22
- 狀態：**產品規格已依最新決策修訂；尚未授權實作**
- 優先順序：本文件取代 v1.1 中第五功能的重量／動作資料庫／歷史紀錄 MVP 規劃；原有四大功能不在此次修改範圍。

## 1. 產品定位與已確認決策
第五功能名稱「小貓能量站」。透過溫和的呼吸與動作節奏引導，提供**引導循環自動計數**與組間休息，讓使用者自行決定是否跟隨；不要求完成任何次數。原始小貓圖片先作靜態佔位，正式 3D 模型須另經使用者核准。介面繁體中文、低刺激、隱私優先、免登入。

**重要語意：系統只能知道播放了幾次完整引導循環，不能確認使用者實際做了幾下。** 顯示「引導 8 次」，不得標示「實際完成 8 下」或假稱偵測到動作。沒有攝影機、麥克風、動作感測。

## 2. 安全與呼吸原則
- 常見啞鈴彎舉：用力舉起時**自然吐氣**，控制放下時**自然吸氣**；但不是所有重訓動作都適用同一口令，MVP 明確標示「示範：啞鈴彎舉／一般輕量動作」，不宣稱適用所有動作。
- 不強迫同步呼吸、屏氣、憋氣或延長呼吸；引導速度僅供參考，使用者以舒適呼吸及正確動作為先。
- 訓練開始前簡短說明：「不需要勉強跟上；感到頭暈、胸痛、呼吸困難或明顯不適時，請停止並尋求適當協助。」不以此取代醫療或專業運動指導。
- 不能將節奏播放當成姿勢安全驗證；重訓過程不鼓勵盯著螢幕。提供語音／柔和提示音選項，預設靜音或由使用者主動開啟。

## 3. MVP 範圍
### 必做
1. 開始畫面：簡短安全說明；選擇每組引導目標 `不限 / 6 / 8 / 10 / 12`（預設 10；不限可無限播放直到停止）。
2. 引導速度：預設「舒緩」單次循環 6 秒（吐氣舉起 3 秒、吸氣放下 3 秒）；可選「較慢」8 秒（4+4）、「舒緩」6 秒（3+3）、「稍快」4 秒（2+2）。節奏不是醫療呼吸處方；切換速度僅在下一循環開始生效。
3. 引導介面：大型文字「自然吐氣・慢慢舉起」／「自然吸氣・慢慢放下」，柔和進度提示；減少動畫時改為靜態文字與進度數字。
4. **A 引導式自動計數**：只有一整個「舉起＋放下」循環走完才加 1；數字標示「已引導 X 次」，不聲稱是實際動作數。中途暫停、停止、跳離、重新整理不得把未完成循環算入。
5. 組數：顯示「第 N 組」；達到預設引導目標時自動停止引導並進入「本組引導結束」畫面，**不強制啟動下一組**；不限模式由使用者自行結束本組。
6. 組間休息：預設 90 秒；可選 30 / 60 / 90 / 120 / 180 秒；暫停、繼續、+30 秒、略過、再休息；時間到只溫和提示，絕不自動開始下一組。
7. 全程有「暫停／繼續」「結束本組」「離開」；無負面文字、無分數、無排名、無連續打卡。
8. 小貓區：可用**使用者原始小貓照片，或本輪核准的正面參考裁切素材**靜態顯示；若素材未進入 repo，用中性佔位框，禁止另生成或換貓；不製作假的 3D 互動。
9. 音訊、低動態、夜間模式；支援手機、平板、桌面、鍵盤及螢幕閱讀器。
10. 本機偏好設定可保存；預設不保存個別訓練歷史。離開即可以清除當次資料。

### 延後至 v2（不列入 MVP）
- kg／lb 重量紀錄與換算（**保留已確認的公斤／磅切換決策，未取消，只是延後**）。
- 動作資料庫、重量／組數訓練日誌、訓練歷史與圖表、AI 姿勢辨識、穿戴裝置、雲端、登入、提醒與推播。
- 正式 3D 模型、動態摸頭及動畫。

## 4. 頁面與互動
1. `EnergyHome`：標題、使用說明、目標選擇、節奏選擇、開始、設定。
2. `GuidedSet`：原圖靜態小貓、當前引導階段、已引導循環數、組別、暫停／繼續、結束本組、離開。
3. `SetComplete`：中性文案「這一組的引導到這裡。可以休息，也可以結束。」、休息／下一組／離開。不得出現達標獎章。
4. `RestScreen`：休息倒數、暫停／繼續、+30 秒、略過、下一組（必須主動點擊）。
5. `Settings`：提示聲音開關與音量、低動態、主題、偏好保存與清除。

狀態轉移：`idle → guiding ↔ pausedGuiding → setComplete → resting ↔ pausedRest → readyNext → guiding`；任意階段可 `exit → idle`。休息可直接略過；不限次數模式可由使用者手動 `setComplete`。返回／重整時不自動啟動引導或聲音。

## 5. 計數及時間規格（工程契約）
- 一個循環 = `exhaleLift` + `inhaleLower`；完成兩段才 `guidedCycles += 1`。
- 計時使用 `performance.now()` 等單調時鐘的累積有效時間，避免 `setInterval` 漂移；UI 更新頻率與邏輯分離。暫停時有效時間凍結。
- 背景分頁／鎖屏：**自動暫停引導**，回前景後須手動繼續；不補計背景期間的循環，亦不自動播音。
- 若按「結束本組」時正處於半個循環，半循環不計數。改變速度於下一循環生效，不重算已完成循環。
- 達目標時只完成目前循環並停止；絕不進入下一次引導。`不限` 無自動結束。
- 組間休息倒數以單調時間扣除已運行時間；分頁背景時**休息倒數自動暫停**，避免回來已錯過提示。休息結束時僅顯示靜態狀態。
- 導引循環數是**引導播放次數**，不是實際運動次數。可提供「我沒有跟上也沒關係」說明。

## 6. 資料型別建議
```ts
type Pace = 'slow' | 'gentle' | 'brisk'; // 8, 6, 4 seconds per cycle
type RepTarget = 6 | 8 | 10 | 12 | null; // null = 不限
type Phase = 'exhaleLift' | 'inhaleLower';
type Mode = 'idle' | 'guiding' | 'pausedGuiding' | 'setComplete' | 'resting' | 'pausedRest' | 'readyNext';
type EnergySettings = { pace: Pace; target: RepTarget; restSeconds: 30 | 60 | 90 | 120 | 180; soundEnabled: boolean; volume: number; reducedMotion: boolean; theme: 'system'|'light'|'dark' };
type EnergySession = { mode: Mode; setIndex: number; guidedCycles: number; phase: Phase | null; activeElapsedMs: number; restRemainingMs: number };
```
只持久化 `EnergySettings`（localStorage）；`EnergySession` 預設僅記憶體存在，重整後回 idle，避免意外恢復運動。沒有身分資料、健康資訊上傳或第三方分析追蹤。

## 7. 無障礙與文字規則
- 可讀文字為主要引導，色彩不可作為唯一辨識；點擊區至少約 44×44 CSS px，清楚焦點樣式。
- 不以高頻閃爍、強制震動、刺耳鈴聲刺激；尊重 `prefers-reduced-motion`。
- 允許完全關閉聲音，關閉後所有核心功能可用；音效須先經使用者操作授權。
- 不顯示「失敗」「落後」「必須完成」「沒跟上」等壓力文字。

## 8. 驗收標準（必要）
- [ ] 完整 6 秒循環加 1；3 秒半循環不加 1。
- [ ] 暫停 20 秒再繼續，不偷加次數；停止時不計未完成循環。
- [ ] 切到背景 60 秒後回來維持暫停，次數不變；必須手動繼續。
- [ ] 達 10 次時自動結束引導，不自動下一組；不限模式不自動停止。
- [ ] 休息可暫停、+30 秒、略過；休息結束不自動開始訓練。
- [ ] 調整速度在下一完整循環生效；無重複或漏計。
- [ ] 聲音關閉、低動態、深色模式均可完整使用。
- [ ] 小貓只使用原始素材或中性佔位；不得未經核准用六視角圖替代；本輪已核准正面單張裁去標籤作靜態角色素材。
- [ ] iOS Safari、Android Chrome、桌面 Chrome/Edge 基本操作可用；有測試記錄。
- [ ] 原有四大功能不受影響，無登入與外部資料傳輸。

## 9. 風險與待確認
- 呼吸提示對不同動作不一定適用：MVP 明確限定示範為啞鈴彎舉等一般輕量動作；不得宣稱適用全部重訓。
- 預設 6 秒、10 次、90 秒為**待使用者體驗確認的產品預設值**，不是運動處方。
- 開發前需核對現有 repo 架構與原始小貓圖是否可取得；未授權時只提出方案不修改程式。
